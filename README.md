# Operating Systems — Theory Examples

This repository contains the source code and supporting materials used in the theory slides for the **Operating Systems** course at UC3M.

The examples are organized into folders by topic, following the structure of the course. 

## Repository Structure

```text
.
├── Introduction to C/
├── Introduction to Operating Systems/
├── Processes/
├── Concurrency/
├── File systems/
├── Memory management/
```

## Requirements

Common tools may required:

* GCC 
* GNU Make
* POSIX-compatible operating system
* Bash or another Unix-like shell

## Purpose

These programs are designed for educational purposes and illustrate concepts discussed during the theory lectures, including:

* Processes and system calls
* Threads and concurrency
* Synchronization mechanisms
* Deadlocks
* Inter-process communication
* Input/output and storage
